memory_summary: Preserve architectural authority, units, metadata, and validation through the Rhino-to-Blender pipeline.
memory_class: procedural_tool_call

Rhino is authoritative for architectural geometry; Blender is authoritative only for visualization. Derive geometry from source curves and measured edges. Preserve units, axes, layer paths, object names, stable identifiers, materials, and placements. Perform one bounded mutation per reviewed construction unit and validate it before continuing. At handoff, require per-object X/Y/Z bounding-box parity and plan plus axonometric inspection; matching object counts alone is not proof. ComfyUI output is visualization and never geometry evidence.
