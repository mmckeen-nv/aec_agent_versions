# Full-build demo installation

Use the canonical Windows installer and operator guide:

**[../../DEPLOY.md](../../DEPLOY.md)**

Do not manually create a Hermes profile or attach RhinoMCP directly. The top-level installer
deploys the isolated full-build profile, pinned runtime, bundled Rhino plug-in, memory seed, and
desktop shortcut.

The numbered files in this directory contain component-level maintainer notes. They are not the
normal operator installation path.
