# Cliff House full-build rules

- Begin from an empty Rhino document in metres and a clean Blender scene.
- Follow the active phase prompts in order and stop at every review gate.
- Use one visible, named modeling operation per MCP call where the prompt requires live pacing.
- Keep references read-only; never load a completed hero/master model as the build source.
- Write scratch data, working documents, receipts, and renders only under ignored run directories.
- Do not use machine-specific absolute paths.
- Do not change Hermes inference, credentials, profile, project, or MCP settings.
- Never print secrets.
