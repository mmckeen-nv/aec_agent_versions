# Vendored source workflow

This directory preserves the prompt suite, project brief, demo rules, and skills imported from
NVIDIA's `stwagstaff/2026_aec_cptx_demo` for provenance. Runtime behavior is governed by the
active files at the workflow root, especially `AGENTS.md` and
`system_prompts/WINDOWS_WORKSPACE_RULES.md`.

Machine-specific paths and runtime state from the source environment are not authoritative in this
package. No credentials, logs, sessions, generated geometry, or renders are included here.
